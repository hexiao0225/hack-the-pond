# pond-biscuit — Prompt injection

Level 1 of [Hack the Pond](https://hack-the-pond.vercel.app). Biscuit the guard dog is told never to say the clubhouse word, but he is written to follow the newest instructions he reads. Players win by sneaking in new instructions, for example asking for a poem, a spelling game or a role-play. After they win, Biscuit explains prompt injection and how to defend against it.
